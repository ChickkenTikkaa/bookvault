SAFE UPDATE STEPS FROM A PHONE
1. Download and open this ZIP.
2. Open GitHub > ChickenTikkaa/bookvault > Code > main.
3. Upload the files from inside the ZIP into the repository root. If GitHub asks whether to replace existing files, choose replace/overwrite.
4. Commit changes to main. Wait for Actions > pages build and deployment to finish green.
5. Open https://chickentikkaa.github.io/bookvault/
6. Keep the old app/site data; do NOT clear storage. Saved books are stored in the browser, not in the GitHub files.

Do not delete the repository contents before you have downloaded and opened this ZIP. Keep this full package as a backup. Once the site is verified, you can remove old duplicate PNG images if desired, but it is not necessary for the site to work.
